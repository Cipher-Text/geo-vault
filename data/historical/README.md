# Historical Data

These collections are reserved for sourced historical geographic and political records. Records should use stable entity IDs, explicit validity dates, and source attribution. Empty collections are intentional until records can be added with reliable sources.

| File | Intended content |
| --- | --- |
| `countries.json` | Historical country and territory records |
| `country-names.json` | Former, official, and renamed country names |
| `capitals.json` | Historical capitals and capital changes |
| `boundaries.json` | Historical boundary or territory changes |
| `administrative-changes.json` | Created, merged, split, or dissolved divisions |
| `former-countries.json` | Former countries, territories, and successor relationships |
| `renamed-places.json` | Renamed cities, regions, and geographic places |
| `historical-cities.json` | Historical cities and former populated places |
| `historical-population.json` | Population estimates with census year or reference date |
| `events.json` | Dated geographic and political events |
